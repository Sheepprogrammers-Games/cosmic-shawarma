# 产品设计

## 1. 定位

《银河系米其林指南：虫洞卷饼摊》是一款单屏限时模拟经营游戏。玩家在小行星带 3 号星门服务区经营一个外星卷饼摊，按外星顾客的图标订单现场制作卷饼、炸物与饮料，用赚到的星币堆自动化设备与店面等级，最终通过银河米其林匿名评审官的三次暗访拿下三星。

结构照《沙威玛传奇》，皮换成外星霓虹手绘，终点换成米其林三星。

## 2. 目标与判据

| 目标 | 判据 |
| :--- | :--- |
| 30 秒内看懂 | 无教程文本，首日只开放 2 种食材，靠订单气泡自解释 |
| 单局可通关 | 15–25 分钟从摊位打到三星，出结算头条 |
| 有可传播画面 | 结算报纸头条 + 三星大厅 + 发光肉柱，任一截图可当封面 |
| 手机能玩 | 横屏，工位单指点击 + 成品短拖拽，最小点击区 88×88 逻辑像素 |
| 包体够小 | 首屏 ≤ 2MB，总包 ≤ 8MB |
| 主题契合 | 米其林评审是主线机制，不是贴皮 |

## 3. 世界观与角色

**场景**：小行星带 3 号星门服务区。虫洞跃迁的飞船必须在此排队等航道，饥饿的旅客只能吃你这一家。招牌是一根竖立的发光旋转肉柱，在深空里像一盏灯塔。

**主角**：一名不露脸的摊主（玩家即摊主，只出现手部与工具，省一整套角色动画）。

**助手 ARM-7**：一台二手机械臂，默认在角落打瞌睡。点它补货；做废的成品丢给它焚化；送去培训后自动补料。它承担《沙威玛传奇》里"员工"的全部功能。

**常规顾客**（点单口味各有偏好，形成记忆点）

| 顾客 | 特性 | 偏好 |
| :--- | :--- | :--- |
| 硅基晶体人 | 耐心长，付钱多 | 忌液体，爱矿物质：星尘盐、陨石薯条 |
| 等离子发光体 | 耐心极短 | 必点冷饮降温，超时会"过热"并烧掉招牌口碑 |
| 章鱼星际海盗 | 单价高、脾气差 | 要反物质辣椒，越辣加分越高 |
| 机械蜂群 | 一次点 3 份小单 | 只吃标准配置，多加任何料都扣分 |
| 黏菌集群 | 慢，会溢出到台面 | 什么都吃，加星尘糖浆得分翻倍 |
| 人类漂流宇航员 | 中庸，剧情彩蛋 | 只想吃"最像地球食物的东西"（不加发光料） |

**事件顾客**（发泄阀与节奏打断，见玩法规格第 6 节）：拾荒机器人、量子小偷、差评虫、虫洞蠕虫。

**Boss 顾客**：银河米其林匿名评审官，三种随机外形，共同特征是墨镜与悬浮记事板。

## 4. 核心循环

```
迎客 → 读图标订单 → 取饼皮 → 按单加料（切肉/触须/星云酱/薯条）
     → 卷制 → 包装 → 出餐 → 顾客付款落币 → 手动收币
     → 营业时间结束 → 日结算（营业额/订单数/完美率/口碑）
     → 升级商店（自动化 / 店面 / 菜单）→ 次日开门
     → 每 N 天：米其林评审官暗访 → 拿星 → 售价倍率跃升、解锁新层级
```

三层嵌套：**单笔订单**（10–20 秒）→ **一个营业日**（60–180 秒）→ **一次星级跃升**（5–15 天）。

## 5. 情绪曲线

这是设计的主轴，一切数值都为它服务。

| 阶段 | 天数 | 玩家状态 | 设计手段 |
| :--- | :--- | :--- | :--- |
| 手忙脚乱 | 1–4 | 手不够用，钱都收不完 | 只有 2 种料，但营业时间短、补货频繁、金币会被扫走 |
| 尝到甜头 | 5–9 | 拿到一星，售价翻倍 | 首次评审给到 1.5 倍售价，收入体感突变 |
| 贪心陷阱 | 10–16 | 解锁新菜品后更乱 | 菜单解锁提升单价上限但增加操作复杂度，UI 明确提示"先堆自动化" |
| 流水线成型 | 17–24 | 机器接手大半 | 自动切肉/自动卷/自动包装陆续到位 |
| 资本家高潮 | 25–29 | 只需点单与收尾 | 清扫机器人自动收币——《沙威玛传奇》最强解放感的等价物 |
| 加冕 | 30 | 三星，报纸头条 | 三星大厅 + 结算头条 + 分享按钮 |

## 6. 与《沙威玛传奇》的取舍对照

| 沙威玛的设计 | 本项目 | 理由 |
| :--- | :--- | :--- |
| 忘收钱当天收入归零 | 金币落台 8 秒后被扫地机器人吸走 | 归零惩罚在 20 分钟单局里过重，会直接劝退 |
| 无明确结局 | 三星通关 + 结算头条 | 补上终点，且绑定活动主题 |
| 只评"对不对" | 配料准确度 / 等待时长 / 火候 三项加权 | 让米其林评分显得可信，也给高手空间 |
| 中文方言配音 | 外星胡言乱语 + 变调 | 同等滑稽，零本地化成本 |
| 20 天才出小偷 | 第 3/8/12/18 天四种事件顾客 | 单局压缩到 30 天，打断节奏必须提前 |
| 烤盘后期难度陡增 | 保留焦糊机制，但自动炸锅与自动切肉可解 | 保留紧张感，同时给出解法 |

## 7. 明确不做

- 不做场景切换、不做摄像机；顾客只在单屏内从屏外走入。
- 不做关卡地图与剧情对话树；以 30 日关卡进度 + 通关后无尽模式承载长期目标。
- 不做联网、排行榜、账号、内购。
- 不做序列帧动画（除肉柱 3 态与 ARM-7 3 态），动感一律靠位移/缩放/旋转补间与粒子。
- 不做竖屏专属布局，竖屏只显示"请横屏"提示图。
