## 1.1 主菜单、关卡与模式

- 启动先进入主菜单，不直接开营业日。
- **关卡模式**共 30 关（日），HUD 显示 `关卡 N/30`，主菜单进度条记录已完成关卡。
- 完成第 30 关后解锁**无尽模式**；无尽模式显示当前波次并持续生成订单，不触发关卡评审结局。
- 无尽模式开放「无尽科技」高级设备：量子保鲜舱、引力扩容台、相位包装器；它们只提供经营上限/节奏加成，不替玩家拖拽出餐。
- 主菜单展示成就墙，记录首次出餐、完美订单、三客同堂、手动收币、全菜单、通关与无尽波次等成就。

## 2. 逐工位交互

工位操作保持**单指点击**；只有最终成品使用短距离拖拽，避免误触：从包装台拖到顾客头顶才算出餐。

### 2.1 饼皮堆（卷制台左侧）

点击 → 一张菌毯饼皮落到卷制台，进入"敞开"状态，可加料。台上已有饼皮时点击无效。

### 2.2 烤肉柱

- 肉柱持续做装饰性脉动；玩家**不需要翻滚或等待火候窗口**。
- 点击 = 从当前库存切下一片肉，落入肉柱下方的备料槽（容量 3 片），每片肉的质量固定为满值。
- 点击备料槽中的肉片 → 加到卷制台的饼上。若无饼皮，操作无效并播放否定音。
- 烤肉库存耗尽后，点击左侧 ARM-7 补货；补货完成后库存恢复。自动化升级仍可代替手动补货和切片。

### 2.3 荧光触须格 / 星云酱格

- 点击 = 直接加一份到饼上（触须为片、星云酱为一挤）。
- 各格有 10 份库存，用尽后格子变灰，需点击 ARM-7 补货（补货耗时 1.5 秒，培训后自动）。

### 2.4 陨石薯条炸锅

- 点击炸锅 = 下一篮生薯条，8 秒炸熟，进入 3 秒"最佳窗口"，之后开始焦化，14 秒彻底焦掉并触发警报音。
- 点击已熟的炸锅 = 取出一份熟薯条到暂存盘（容量 2 份）。
- 点击暂存盘 = 把薯条加到饼上（作为夹料）或作为独立小食装入包装。
- 焦掉的一篮必须点击"倒掉"（或丢给 ARM-7），占用 2 秒。
- 升级"自动炸锅"后：自动下篮、自动在最佳窗口出锅，永不焦。

### 2.5 饮料机

- 三个出液口对应三种饮料（反物质气泡水 / 超新星浓缩汁 / 等离子奶昔，后两者需解锁）。
- 点击杯架取空杯 → 点击出液口注满（1.2 秒，注液期间可去做别的事，但超过 2.4 秒会溢出，溢出则该杯作废）。
- 升级"自动饮料机"后：点击出液口一次即得成品杯，不会溢出。

### 2.6 卷制台

- 饼上料齐后点击"卷"按钮（或直接点击饼）→ 0.6 秒卷制动画 → 变为"已卷"。
- 已卷的卷饼**不可再加料**。加错料只能整份丢给 ARM-7 焚化（1 秒），料损失。
- 升级"自动卷饼机"后：料齐并匹配任一在场订单时自动卷。

### 2.7 包装台

- 点击已卷卷饼 → 移到包装台 → 点击包装 → 0.5 秒 → 成为可出餐的成品袋。
- 成品袋可容纳：1 卷饼 + 0–1 小食 + 0–1 饮料。点击暂存的薯条/饮料即塞入当前袋。
- 包装台上方显示「成品袋内容」小框，逐项列出肉、触须、酱、辣椒、薯条、饮料及其 `×数量`；配料未卷制时显示「当前配料」小框。
- 升级"自动包装机"后：卷好即自动包装。

### 2.8 出餐

- 按住包装台的成品袋拖到目标顾客头顶再松手；点击顾客不会触发出餐。
- 交付即结算评分。`S < 0.75` 时顾客拒收并保持等待、成品袋不清空；达到满意阈值才播放满意表情、离场并**在台面落下星币**。

### 2.9 收币

- 星币落在柜台随机位置，点击收取。
- 停留 8 秒后被扫地机器人吸走（丢失）。口碑越高，停留时间越长（+0.05 秒/口碑点，上限 14 秒）。
- 升级"清扫机器人改装"后：金币自动收取。

### 2.10 ARM-7

- 点击 = 补一格库存（优先补空得最久的格子），耗时 1.5 秒，期间不可再点。
- 拖不动的错误成品/焦薯条点击后再点 ARM-7 = 焚化。
- 培训 Lv1/2/3 后：自动补货，间隔 6 / 4 / 2 秒。

## 3. 订单与评分

### 3.1 订单生成

订单 = `{ 卷饼配料集合, 小食 0-1, 饮料 0-1 }`

- 配料从已解锁食材中抽取，数量随天数上升：第 1–4 天 1–2 种，第 5–14 天 2–3 种，第 15 天起 2–4 种，可含重复（如"肉 ×2"）。
- 小食/饮料出现概率随解锁进度上升，至第 20 天后约 70% 订单含饮料。
- 顾客偏好（见产品设计第 3 节）会加权抽取，让每种顾客的单看起来"像它自己"。
- 气泡**全图标无文字**，配料按数量重复画图标，最多 6 个图标，超出折行。
- 每个订单图标右上角带 `×数量` 小徽章，顾客需要两份或三份时不靠猜图标数量。
- 顾客不会在开局瞬移到队列：每批随机进入 1–3 人，从屏幕右侧外滑入，并以 0.45 秒间隔错峰到位。

### 3.2 顾客耐心

`耐心时长 = 基础(18s) × 顾客系数 × (1 + 店面等级 × 0.15)`

顾客系数：硅基 1.4 / 黏菌 1.3 / 宇航员 1.0 / 海盗 0.9 / 蜂群 0.85 / 等离子 0.65

耐心条走完 → 顾客愤怒离场，口碑 -5，无收入。等离子体超时额外 -5。

### 3.3 评分公式

```
配料分 A = max(0, 1 - 缺失项×0.34 - 多余项×0.25)      权重 0.40
等待分 W = 剩余耐心比例（线性）                        权重 0.40
火候分 H = 各火候相关部件的 heat 质量均值              权重 0.20
   肉片：|heat - 最佳| 归一化；薯条：熟/最佳/焦 → 1.0/1.15/0.0
   订单不含火候部件时，H 记为 1.0

总分 S = clamp(0, 1, 0.40A + 0.40W + 0.20H)
```

**小费倍率** `tip = 0.5 + 1.5 × S`（0.5×–2.0×）
**口碑变化** `Δrep = round(-6 + 16 × S)`（S=1 时 +10，S≤0.4 时为负）
**完美单** `S ≥ 0.97` → 额外 +50% 星币，播放三星特效，完美率计入日结算。

### 3.4 收入

`单笔收入 = 订单基础价 × 店面倍率 × 星级倍率 × tip`

订单基础价：卷饼 6 + 每份配料 2 + 小食 4 + 饮料 5（星尘糖浆 +3）

## 4. 时间与天数

- 第 1 天营业 60 秒；每天 +6 秒；店面每升一级 +20 秒；上限 180 秒。
- 营业结束 → 场上顾客立刻离场（不结算）→ 日结算面板 → 升级商店 → 次日。
- 总长 30 天。日结算面板显示：营业额、订单数、完美率、口碑、当前星级进度。

## 7. 米其林评审（主线）

| 天数 | 事件 | 达标线 | 奖励 |
| :-- | :--- | :-- | :--- |
| 5 | 一星暗访 | 该单 S ≥ 0.80 且当日口碑 ≥ 30 | 一星，星级倍率 1.5，解锁食材第 3 格 |
| 15 | 二星暗访 | S ≥ 0.88 且口碑 ≥ 90 | 二星，倍率 2.5，解锁自动化 A7–A10 |
| 30 | 三星终审 | 连续 3 单均 S ≥ 0.90 | 三星，倍率 4.0，通关 |

**暗访机制**

- 评审官混在队列里入场，外观有墨镜与悬浮记事板，但**不加任何提示文字**——玩家自己认出来才有暗访的味道。
- 他的订单气泡是**谜语式的意象图**而非配料图标，例如：
  - 一座火山的剪影 → 需含反物质辣椒 ×2
  - 一片蓝色地球天空 → 需不含任何发光食材
  - 一颗爆炸的恒星 → 需含超新星浓缩汁 + 星尘糖浆
- 谜语共 6 组，每次随机 1 组；解错不会立刻失败，按普通评分算，只是拿不到星。
- 未达标：该星级推迟 3 天重来，最多重试 2 次；三星终审失败则以当前星级结局收尾（有 A/B/C 三种结算文案）。

## 8. 结局与结算

三星达成 → 全屏《银河系米其林指南》报纸头条：

- 头版大图：三星大厅 + 玩家的招牌肉柱
- 标题："3 号星门服务区小摊登顶银河三星"
- 数据栏：总营业额、总订单数、完美率、最高单价、经营天数
- 一个"再来一局（困难模式）"与一个"分享截图"按钮

困难模式（若时间允许，属 P2）：顾客耐心 ×0.75，营业时长不增长，30 天硬性拿三星。
