# 美术与音频规格

## 1. 风格定调

**一句话**：粗描边手绘卡通 + 深空霓虹配色 + 平涂单层暗部。看上去像一个约旦街边摊被搬到了赛博霓虹的星门服务区。

《沙威玛传奇》被玩家戏称"简陋"，但它的成功不是因为糙，而是因为**统一**：一套线宽、一套配色、一套光照方向，从头到尾没有破功。本项目照抄这一点，唯一的偏离是把它的暖黄暖褐街边色，替换为深紫底 + 粉青霓虹的外星色。

### 硬性风格规则（每一张图都要满足）

1. **描边**：深紫黑 `#1B1033`，2x 出图下线宽 6–8px（等效 3–4 逻辑像素）。线条允许不闭合、允许出头，但**线宽全局一致**，不做粗细变化的书法感线条。
2. **上色**：平涂。每个色块只加一层暗部，`multiply` 15%，暗部统一在**左下方**（光源在右上方的招牌肉柱）。禁止渐变，禁止柔边阴影。
3. **发光**：所有食材、酱料、饮料、招牌带外发光，两层——内层白色 40% 模糊 4px，外层本体色 60% 模糊 12px。发光是本作的外星标识，非发光物体只有 UI 面板与机器外壳。
4. **透视**：全部正面平视，无消失点。顾客站姿统一 3/4 侧身朝左（面向柜台）。器物一律正面，不做俯视台面。
5. **比例**：卡通头身比 1:2，眼睛占头宽 1/3 以上。器物做圆角，禁止尖锐直角。
6. **不画细节**：单个物件的独立色块数 ≤ 5。分辨率给足但信息量压低，这是省工作量的关键。

### 反例（明确不要）

- 写实质感、金属高光、次表面散射
- 像素风、低多边形、扁平极简（Material 那种）
- 日系赛璐璐三段阴影
- 任何渐变背景板
- 描边粗细不一的"精致手绘"

### 外星感放在哪里（最重要的一条约束）

这是一个限时点击游戏，玩家要在 10 秒内认出四五种食材。**外星感和可读性会打架，处理原则是分层**：

| 层 | 处理 | 原因 |
| :--- | :--- | :--- |
| **剪影** | 保持地球食物的可读轮廓 | 64px 的图标上只剩剪影，认不出就没法玩 |
| **质感与解剖** | 全部外星化 | 荧光血管、复眼纹、孔洞、裂缝、悬浮颗粒 |
| **配色** | 全部外星化 | 用色板里的荧光色，禁止地球食物的暖褐暖黄 |
| **动态** | 全部外星化，且**这是性价比最高的一层** | 会呼吸、会扭动、会漂浮的食材，一眼就不是地球产的，而代码代价几乎为零 |

也就是说：肉片还是肉片的形状，但切面有荧光血管网、落下时会抽动一下。饼还是饼的形状，但它是活体菌毯，孔洞会缓慢开合。**不要为了外星去改剪影**——那是最贵也最伤玩法的做法。

三条硬规则：

1. 每个食材/道具必须在 **64×64 灰度剪影**下仍可辨识，且与同屏其它食材的剪影明显不同。出图后必做剪影测试。
2. 外星化的"活性动态"一律用位移/缩放/旋转补间与粒子实现，**不做序列帧**（唯一例外是肉柱 3 态与口器花 3 态）。
3. 有机体一律不画对称的机械结构；机械体一律不画有机曲线。全场只有 ARM-7 与三台升级机器是机械，其余会动的东西都是活的——这个对比本身就是外星感的来源。

## 3. 出图规范

| 项 | 要求 |
| :--- | :--- |
| 逻辑分辨率 | 1280×720 |
| 出图倍率 | 2x（即按 2560×1440 的画布设计，素材尺寸表已是 2x 尺寸） |
| 格式 | 角色/道具/UI 用 PNG-24 带透明；背景用 JPG 质量 82；图标用单文件 SVG sprite |
| 单文件上限 | 背景 ≤ 400KB，其它 ≤ 200KB |
| 总包上限 | 图片总计 ≤ 5MB，音频 ≤ 3MB |
| 命名 | 全小写下划线，`类别_名称_状态.png`，如 `cust_octopus_angry.png` |
| 裁切 | 紧贴内容裁切，四边留 8px 透明边防止缩放时边缘裁断 |
| 压缩 | 一律过 pngquant / mozjpeg |
| 锚点 | 角色锚点在脚底中心，道具锚点在几何中心，另存 `assets/anchors.json` 记录 |

**活性规范**（全部补间与粒子，不出序列帧）：

- 口器花：待机时缓慢左右摆动 ±5°；接近它时花瓣微张（预期反馈）；吞食是 闭合→张开→咀嚼→闭合 三张图切换，共 1.0s。
- 拾荒蛞蝓：从屏幕左侧爬入、直线爬到目标星币、吞下、爬出。速度慢到玩家来得及抢——**它的存在就是给玩家"再快一点"的压力**。
- 气囊水母：上下浮动 ±8px，触须正弦摆动，光核亮度跟着 BGM 节拍脉动（读音频振幅或按固定 BPM 计时）。
- 星门蟑螂：横向直线快跑，跑动中带 `fx_streak` 尾迹。

**为什么用生物替代机器**：口器花比"焚化炉"好画、好做反馈（张嘴吞掉有即时快感），蛞蝓比"扫地机器人"更能表达"你的钱被活物吃了"的心理压力，水母给了整个场景一个不用画灯具的照明解释。三者都省素材、都更外星。

### 4.5 外星顾客（3 身 + 15 头 = 18 张）

**换头策略**：做 3 套通用身体（人形站姿 / 软体 / 大体型），每种顾客只画头部与一件标志物，运行时组合。表情通过替换头部图实现，只给三位主力顾客做 3 表情。

身体（各 384×384）：`body_humanoid.png`、`body_blob.png`、`body_large.png`

**设计要求**：每个外星顾客必须满足「**一句话能说清、剪影一眼能分辨**」。做法是每位只给一个强特征（一种非人类的解剖结构）+ 一件叙事道具，不堆细节。禁止「人形 + 尖耳朵 + 绿皮」这种偷懒外星人。

身体三套的外星化处理：`body_humanoid` 不是人类比例——躯干偏长、四肢关节数比人多一节；`body_blob` 无骨、底部摊开、边缘半透明；`body_large` 厚重、有外骨骼板。

## 7. AI 生成要求

活动提供 AI 工具费用报销（上限 ¥200/人），素材主体走 AI 生成 + 人工统一，但必须遵守下列约束，否则一致性会崩。

**图像**

1. 先手工确定 3 张"锚定图"（一个顾客、一件食材、一台机器），把风格钉死，之后所有生成都以锚定图为参考。
2. 固定一套 style prompt 后缀不变：粗描边手绘卡通、平涂、单层左下暗部、正面平视、透明背景、霓虹发光、深紫底色调。
3. 同一批次固定随机种子，只改主体描述。
4. **每张出图后必做三步后处理**：① 抠净背景；② 按第 2 节色板做色彩映射（量化到色板色）；③ 统一重描边到 6–8px。跳过这三步的素材不得入库。
5. 顾客一律只生成头部，身体用手工画的 3 套通用件，保证站姿与比例绝对统一。
6. **食材的 prompt 必须分开写剪影与质感**：先写地球食物的形状（"a flatbread wrap"、"a slice of grilled meat"），再追加外星质感描述（"bioluminescent veins"、"breathing pores"、"floating star specks"）。反过来写会得到认不出是食物的东西。
7. **外星生物与外星顾客不许出现"人形绿皮尖耳"这类通用外星人**。prompt 必须点明具体非人类解剖结构：`compound eyes covering the whole head`、`ring of concentric teeth`、`five floating eyeballs`、`mushroom cap with spore curtain`、`cluster of hexagonal prisms with a light core inside`。
8. 有机体与机械件**分两批生成**，两批用不同的质感词（有机：wet, fleshy, translucent, veined；机械：worn metal, rivets, chipped paint, matte），避免风格互相污染。

**音频**

1. 主题曲提示词要素：Middle Eastern Hijaz scale hook、retro synth、4/4 electronic beat、loopable、upbeat、lo-fi 质感。
2. 语音用 TTS 生成任意语言的短句后做变调与倒放处理，得到 gibberish；不要使用可辨识的真实语言，避免误解。
3. 全部音频过一遍归一化到 -14 LUFS，音效峰值不超过 -1dBFS。

**版权**：所有素材必须为 AI 生成或 CC0 来源，不使用任何来源不明的图片与音频，不使用有商标特征的元素（包括真实米其林 logo，星徽自行设计）。
