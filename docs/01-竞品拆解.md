## 2. 玩法逆推（单屏结构）

整局游戏不切场景、角色不移动，所有交互压在一屏内。这是它能低成本高完成度的根本原因，也是本项目要照抄的第一条结构决策。

**屏幕分区**

- 左侧：员工。点击他补货；做错的成品丢给他销毁（"垃圾桶"）。培训后会自动补充食材。
- 中部台面：四个食材格（烤肉 / 黄瓜 / 沙拉酱 / 薯条）、卷饼、包装。
- 右侧机器：炸薯条机、橙汁机 / 可乐机。

**一单流程**

1. 顾客走到柜台，头顶以图标形式给出订单。
2. 玩家按订单点击食材堆叠到饼上 → 卷起 → 包装 → 递出。
3. 顾客把金币放在桌上。
4. **玩家必须手动点击收钱**，忘记收取则当天收入归零。

第 4 步是设计上的关键：它把"钱"也变成一个需要抢时间的操作，制造持续忙碌感，也让后期的"自动收钱"升级成为最大的解放感来源。

**天与升级**

- 每天有营业时间限制，随天数增长与店铺升级不断延长。
- 金币投向三条线：自动化设备（人工培训、饼机、包装机、切土豆、切肉、炸土豆）、店面等级（提升售价）、新菜品与饮料。
- 社区共识的最优顺序：前期 200 买饮料 → 自动化全部升满 → 1800 升店面提售价 → 每存够 6000–10000 解锁一样新小吃/饮料 → 烤盘留到最后一次拉满。
- 后期高度自动化，几近自给自足。

**事件顾客**

- 第 10 天解锁乞丐：拿餐不付钱，敲他的头才付。
- 第 20 天解锁小偷：多敲几次才交出金币。

**通关**

没有硬性结局，社区约定的终点是把店做成"一个三明治卖 36 美元、日入 5 万美元的网红打卡店"。

**难度拐点**

玩家反馈集中在两点：一是升级不能"开枝散叶"，可做的东西一多就手忙脚乱；二是烤盘升级后要同时管节奏与火候，难度陡增。

## 3. 爆火归因（哪些是可以复制的，哪些不是）

| 因素 | 可复制性 | 本项目对策 |
| :--- | :--- | :--- |
| 单屏、零学习成本、即开即玩 | 高 | 完全照抄结构 |
| 手动收钱制造的忙碌感 | 高 | 保留，并把"自动收钱"设为终极升级 |
| 自动化带来的身份翻转（打工人→资本家） | 高 | 保留为核心情绪曲线 |
| 敲打乞丐/小偷的发泄阀 | 高 | 保留并外星化，扩到 4 种事件顾客 |
| 魔性主题曲 + 搞笑配音（唐山/东北/新疆混搭） | 中 | 用"外星胡言乱语 + 变调"替代方言，天然滑稽且零本地化成本 |
| "简陋"但统一的手绘画风、被戏称 AI 三件套 | 中 | 保留手绘感，但配色与描边强制统一，避免真的糙 |
| 主播传播 + 短视频二创的时代红利 | 低 | 不可复制，不作为设计依据 |

结论：可复制的是**结构与情绪曲线**，不是画风的粗糙度。所以本项目在美术上要做的是"低工作量但高一致性"，而非"故意做丑"。

## 4. 老爹系列（Flipline Gameria）——成熟范式补强

《沙威玛传奇》玩法本身并不新鲜，其上游范式是 Flipline 的老爹系列。后者在评分与养成上比沙威玛完善得多，值得选择性吸收。

- **四工位流水线**：点单站 → 烤制站 → 组装站 → 饮料/摆盘站，逐站拖拽点击。
- **分站评分取平均**：每站独立评订单准确度，四站取均值；有修饰系数（如 170% 特色加成按 1.7 倍计）；单站低于 67% 则特殊请求顾客不给分。
- **评的不只是配料**：还评等待时长、火候精确度、装配完成度。
- **星级顾客**：准确出单积累星星，顾客晋升铜/银/金奖章，之后小费更高、点单更快、给分更高。
- **店内陈设影响耐心**：大厅摆件越多，顾客愿意等的时间越长；应季主题道具得分翻倍。
- **分数→等级→解锁**新顾客、新食材、服装与家具。

**吸收清单**（4 天工期下的取舍）

| 老爹机制 | 是否采纳 | 理由 |
| :--- | :--- | :--- |
| 多维度评分（配料/等待/火候） | 采纳，简化为 3 项加权 | 是"米其林评审"合理化的前提 |
| 分数→小费倍率 | 采纳 | 直接接沙威玛的金币循环 |
| 陈设提升顾客耐心 | 采纳，合并进店面等级 | 少做一套家具系统 |
| 四工位切换 | 不采纳 | 与"单屏不切场景"冲突，会显著抬高操作与美术成本 |
| 星级顾客养成 | 不采纳 | 单局 20 分钟撑不起长期养成，改为口碑值一条曲线 |
| 节日主题 | 不采纳 | 周赛作品无运营周期 |

## 5. 本项目要补的那块拼图

沙威玛传奇最大的结构缺陷是**没有终点**——靠玩家自定义"网红店"作为收尾。本项目的差异化正好落在活动主题上：把「米其林匿名评审官暗访」做成周期性 Boss 顾客，一星/二星/三星作为三段明确的里程碑，三星即通关并出报纸头条结算画面。这既解决了缺终点的问题，又让作品与 #银河系米其林指南 强绑定。
