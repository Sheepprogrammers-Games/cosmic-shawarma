## 开始营业

直接打开根目录的 `index.html` 即可进入全屏主菜单首页；首页右侧可独立调整音乐音量、音效音量或一键静音。开发时运行 `npm run build && npm run dev`，然后访问 `http://127.0.0.1:4173/`。

游戏仅支持横屏。顾客会从右侧屏幕外随机成批（每批 1–3 人）走入，站在吧台后面，头顶气泡按订单内容显示食材图标与数量。点击肉柱切肉、点击肉片与备料格加料，制作台上方的小框会实时列出当前配料的种类和数量；依次点击「卷制」「包装」后，小框变成「成品袋内容」。包装完成后必须**按住成品袋拖到对应顾客头顶**，原地点击只会提示需要拖动。评分低于满意阈值会暂缓接收且成品保留，可重做后再次投递。满意的顾客会把星币放在台面，必须点击星币才能收入账；清洁员会在等待过久时将其收走。炸锅需要在最佳窗口捞起；饮料机点击一次开始注液、达到刻度后再次点击停止。每天收摊后可在升级站购买自动化、店面和新菜单，30 天内通过三次星级评审即可达成三星目标。

关卡时长从第 1 关 32 秒起逐日递增，店面升级还会额外延长营业时间，上限 55 秒。

主菜单提供「关卡模式」与「无尽模式」：完成 30 个关卡日后解锁无尽模式和无尽科技设备。菜单同时展示关卡进度与成就。首次点击会解锁声音，顶栏音符按钮可静音。存档在日结时写入浏览器 `localStorage`；通关页可返回主菜单。

## 调试

开发控制台提供 `window.__dbg`，可调整星币、口碑、天数与星级，买满升级，强制生成顾客/事件/评审官/生物，切换结局和营业倍速。

## 素材生成

`assets/images/` 下的素材为成品，直接被游戏加载。四个事件角色头像与谜语记事板由 `tools/draw_event_art.py` 生成（依赖 Pillow，四倍超采样后缩放）：

```bash
python3 tools/draw_event_art.py            # 写入 assets/images
python3 tools/draw_event_art.py /tmp/out   # 只生成预览，不覆盖成品
```

## 与同目录 galaxy-bistro 的关系

`galaxy-bistro` 走的是「荒野 RPG 生存 + 狩猎烹饪」方向，本项目走「餐厅经营」方向，两者是同一主题下的两份独立投稿，代码不共用，仅沿用相同的构建方式与 Canvas 2D 技术栈。
